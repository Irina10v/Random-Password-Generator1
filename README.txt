Random Password Generator
Автор: Близнюков Кирилл
Дата: 5 мая 2026

Описание
GUI-приложение для генерации случайных паролей с возможностью настройки параметров.

Возможности
Настройка длины пароля
Выбор типов символов:
Цифры
Буквы
Спецсимволы
История сгенерированных паролей
Сохранение истории в JSON
Примеры использования
Пример 1: Простой пароль

Параметры:

Длина: 8

Только буквы

Результат:

aBcDeFgH

Пример 2: Пароль для сайта

Параметры:

Длина: 10

Буквы + цифры

Результат:

a9K2mL8pQ1

Запуск
python main.py
